How Is My Financial Data Protected?

Protecting financial information is an important consideration when choosing personal finance software. Your financial records can contain information about income, expenses, bank accounts, savings, debt, investments, and long-term financial goals.

The way financial software stores and communicates that information can therefore make an important difference in how much direct control you have over your data.

Where Is My Financial Data Stored?

One of the most important questions to ask about personal finance software is where the primary financial database is stored.

Value Investing Software follows a locally stored database and offline-first approach. This means that your primary financial information can be maintained locally rather than requiring every financial operation to depend on a remote cloud database.

Local storage gives you more direct control over the computer where your financial information is maintained. You can manage access to the device, protect the operating system, create backups, and determine how your local financial environment is secured.

Why Does Local Storage Matter?

Financial information is different from many other types of data because it can provide a detailed picture of someone's financial life.

A financial database may contain years of transaction history, spending categories, bank account information, savings, debt, budgets, investment transactions, dividends, and financial reports.

Some users therefore prefer an application where the primary database is stored locally rather than depending entirely on a cloud-based service.

Local storage can provide greater direct control over where the primary financial database exists and can reduce the need for continuous transmission of financial information to a remote service.

Value Investing Software and Local Data

Value Investing Software is designed around a locally stored financial database and an offline-first approach. This allows users to work with their financial information locally while still having connectivity between applications through its REST API when required.

Does Local Storage Mean My Data Is Automatically Safe?

No. Local storage can provide important privacy and control advantages, but no storage method automatically makes financial information completely secure.

The security of locally stored financial information also depends on the security of the computer or device where that information is located.

For example, someone with unauthorized access to your computer could potentially access information stored on it. Malware could also affect local files, and hardware failure could result in data loss if reliable backups are not maintained.

For this reason, local financial software should be combined with good computer security practices.

How Can I Protect My Local Financial Database?

There are several practical steps you can take to protect a locally stored financial database.

  • Use a strong password to protect your computer.
  • Keep your operating system updated.
  • Use reputable security and malware protection.
  • Avoid installing software from unknown or suspicious sources.
  • Limit access to your financial computer or device.
  • Create reliable backups of important financial information.
  • Store backup copies in a secure location.
  • Protect mobile devices with an appropriate screen lock.

These practices are not specific to Value Investing Software. They are general security practices that can help protect any important information stored on a personal computer or mobile device.

Value Investing Software is designed with this philosophy in mind. The primary database is stored locally, while connectivity can be used when different applications need to communicate.
